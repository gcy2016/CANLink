刷入 vdlink 固件
请在安卓系统执行以下步骤。
  1. 打开CANable外壳，把 BOOT 两个针脚用导线短接（注意不要短接到其他位置）。
  2. 保持短接状态下重新插上，指示灯亮后可拿掉短接导线。
  3. 点刷入vdlink1.0，在弹窗里选 STM32 BOOTLOADER（或 DFU in FS Mode）。
  4. 等进度走完显示“完成”，即代表固件程序更新成功。拔下来再插上就是新固件。
