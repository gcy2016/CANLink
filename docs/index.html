刷写

通用 UDS 刷写。控制器（请求 / 响应 / 功能寻址 ID、CAN FD、填充字节）在“诊断”页选。安全算法随开屏密码解锁内置好；指纹诊断仪编号自动获取，取不到才用内置值兜底，不用填。刷写流程写成下面的步骤表，换控制器 / 供应商改一份就能刷；支持 S19 / HEX。

刷写文件

Driver （引导驱动，可不选）
App （应用程序）
只收 S19 / HEX（.s19 / .s28 / .s37 / .srec / .mot / .hex / .ihex）。别的格式会明确拒绝，不会当成刷写数据。选文件后这里显示识别出的格式和各段地址 / 大小。
开始前确认：蓄电池电压正常 / 接好充电宝，手机设成不自动锁屏，中途别拔线、别切后台、别关通道。刷写时整车其他控制器会被静默，失败会尝试自动恢复；若提示停在 Boot，重新刷一次。
刷写流程（高级：步骤、指令、等待时间）

默认是标准 UDS 刷写顺序，换控制器 / 供应商改这里。顶层 alfid 地址/长度格式、timeout 每条等待毫秒、recovery 中途失败恢复整车的功能寻址指令；steps 每步有 op（req 物理请求 / func 功能寻址不等应答 / security 安全访问 / fingerprint 写指纹 / tp_on / tp_off 保持在线 / flash 刷文件 / delay 等待）、name、data、wait。flash 步的 file 是 driver/app，erase 先擦除、activate 后激活。

固件

当前：未连接
配套的是 vdlink 固件（在 CANable 2.0 原版 slcan 固件上改的，开源）。原版固件也能用，但时间戳不准、采样点不能调、只听模式不生效。
刷入 vdlink 固件
  1. 拔下 CANable，把 BOOT 两个针脚用跳线帽短接。
  2. 重新插上，这时它是“烧录模式”，不是 CAN 设备。
  3. 点下面的按钮，在弹窗里选 STM32 BOOTLOADER（或 DFU in FS Mode）。
  4. 等进度走完显示“完成”，拔下来、取下跳线帽，再插上就是新固件。
电脑（Windows）上浏览器一般看不到烧录模式的设备（缺驱动），用安卓手机刷最省事；也可以用 ST 官方的 STM32CubeProgrammer 刷 vdlink-1.0.bin（地址 0x08000000）。
