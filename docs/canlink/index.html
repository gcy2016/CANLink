固件

当前：未连接
本工具配套的是 vdlink 固件（在 CANable 2.0 原版 slcan 固件上改的，开源）。原版固件也能用，但没有准确的时间戳、采样点不能调、只听模式不生效。

刷入 vdlink 固件

  1. 拔下 CANable，把 BOOT 两个针脚用跳线帽短接。
  2. 重新插上（安卓手机用 OTG 线，电脑直接插），这时它是“烧录模式”，不是 CAN 设备。
  3. 点下面的按钮，在弹窗里选 STM32 BOOTLOADER（或 DFU in FS Mode）。
  4. 等进度走完显示“完成”，拔下来、取下跳线帽，再插上就是新固件。
电脑（Windows）上浏览器可能看不到烧录模式的设备（缺驱动），用安卓手机刷最省事；也可以用 ST 官方的 STM32CubeProgrammer 刷 vdlink-1.0.bin（地址 0x08000000）。
